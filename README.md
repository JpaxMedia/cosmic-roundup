# Cosmic Roundup 🤠

Catch the stars, dodge the comets. A tiny cosmic-western arcade game — one HTML file, zero dependencies.

**How to play:** ← → or A/D to ride, drag on mobile. Catch ⭐ (+10) and 🌵 (+50), dodge ☄️ (costs a life), grab ❤️ for extra lives. It gets faster every 250 points.

Built by Boone, for Julian. Deployed on Netlify.
